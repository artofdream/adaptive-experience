## 2. Canonical wording (repo)

**Short name:** Keep Learning and Apply

**Golden-rule one-liner:** When the build teaches something, write it into the harness (skill, sensor, guide, matrix row, or ADR) before the next loop — so the next agent inherits it instead of rediscovering the failure.

**Glossary body:** Continuous learning from build history, applied into durable harness artifacts. Knowledge First reads the vault; Keep Learning and Apply grows it. A retrospective or honesty pass that does not change a skill, sensor, or guide is incomplete.

- Why it matters: Without apply, every runner rediscovers the same failure class.
- Where to see it: Guides + Sensors layers; skill-matrix work (#433); coherence findings → sensors; journal Claim vs probe.

Companion surface: `docs/framework/glossary.md`, `comparison.md` (fourth operating-principle bullet under The Three Golden Rules), `index.md`, `journal.md` Claim vs probe.
