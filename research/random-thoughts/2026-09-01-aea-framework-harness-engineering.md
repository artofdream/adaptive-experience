## Abstract

The 31 Aug revision mapped Kocer's five concentric floors onto AEA's Outer Harness. This **1 Sep 2026 revision** adds a second external pattern [23]: a **six-role agent team** (SCOUT → OBSERVER) around one compiled second brain, with a **GUARDIAN before irreversible acts** and an **OBSERVER write-back** so memory compounds. AEA already has multi-hat stakeholdership, vault memory, MRC+CI independence, and Domain Services under the stack. What is new is language — not inventory — for pre-irreversible gating (R1), write-after discipline (R2), and refusal of "no weak links" rhetoric (R6). Renaming AEA's fourteen hats into six generic roles is **rejected** (R8).

## II. ROLE NON-OVERLAP WITHOUT DESTROYING THE FOURTEEN HATS

rvaniaaaa's useful invariant: **one job per agent, explicit stop rule**. AEA's equivalent is the fourteen `@aea-*` skills and the MRC dual-hat lesson (#345): implementer does not self-merge when MRC is not invoked; MRC does not invent product scope. Do **not** collapse hats into SCOUT/ANALYST/STRATEGIST/GUARDIAN/EXECUTOR/OBSERVER. Do **adapt** the charter style (R3).

Approximate mapping (illustrative, not a rename):

| rvaniaaaa | Nearest AEA surface |
|---|---|
| SCOUT / ANALYST | research / knowledge-guardian / performance / UX probes |
| STRATEGIST | product-owner + project-manager sequencing |
| GUARDIAN | Auto-review + sponsor secret pastes + appsec posture (R1 language) |
| EXECUTOR | senior-software-engineer / DSO implementer hats |
| OBSERVER | knowledge-guardian write-after + daily briefs (R2 language) |
| Shared brain | `research/random-thoughts/` + DATE_RE + guards |

Domain Services stay **under** this map. A personal agent kit without fail-closed inventory is not Path B.

## III. GUARDIAN AND OBSERVER AS HONESTY FLAGS

### R1 — Pre-irreversible gate (adapt)
Before send / spend / publish / delete / change accounts: stop for human or existing Auto-review. AEA already practices this for CI variables and Play secrets. Flag: name it in SOPs; do not add an LLM merge judge (K6 remains **reject**).

### R2 — Write-after (adapt)
After consequential acts, write session memory or vault so the next hat starts richer. Knowledge First already requires read-before; write-after is the missing twin in some implementer passes. Flag only.

### R6 — No "no weak links" claim (accept)
Searching for the weak link is permanent. Dual-viewport after CSS stays **Unknown** until probed. Main red on `#348` is a weak link in CI, not a paper victory.
