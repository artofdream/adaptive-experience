# Topic JSON Schemas

Machine-readable payload schemas for MVP topics (NFR-015).

Naming: `{topic}.{semver}.json` (for example,
`support.faq.answered.v1.0.0.json`). Schema versions must match the
**Schema version** column in [`../topic-contracts.md`](../topic-contracts.md).

Add concrete JSON Schema files here when a topic is implemented. Until then,
the markdown catalog remains the reviewed contract of record.
