# Lily's Florist Reference Design

This area is a worked architecture and traceability example. It does not yet
contain executable application code.

Primary MVP pathway:
Discover → Understand → Recommend → Customize → Deliver → Checkout → Track

Customer Memory / CRM ("Remember") is MVP+ / Future scope and is outside this
pathway. See `docs/03-functional-design/customer-journey.md` and
`docs/07-roadmap/roadmap.md`.
